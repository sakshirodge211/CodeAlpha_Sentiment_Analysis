# CodeAlpha Task 4 - Sentiment Analysis

## Project Overview

This project is completed as part of the CodeAlpha Data Analytics Internship.

The objective of this task is to perform Sentiment Analysis on customer and user reviews using Natural Language Processing (NLP).

The project analyzes text reviews and classifies them into Positive, Negative, or Neutral sentiment using the VADER sentiment analysis tool.

## Dataset

The dataset used in this project is the **Sentiment Labelled Sentences Dataset**.

The dataset contains reviews from three sources:

- Amazon
- IMDb
- Yelp

The combined dataset used in this project contains **2,748 reviews**:

- Amazon: 1,000 reviews
- IMDb: 748 reviews
- Yelp: 1,000 reviews

The original dataset labels contain Positive and Negative sentiments.

## Objective

The main objectives of this project are:

- Analyze text reviews
- Perform sentiment classification
- Calculate sentiment scores
- Identify Positive, Negative, and Neutral reviews
- Visualize sentiment distribution
- Compare sentiment across different sources

## Technologies Used

- Python
- Pandas
- Matplotlib
- VADER Sentiment
- Natural Language Processing (NLP)

## Methodology

### 1. Data Loading

The dataset was loaded using Pandas and combined into a single dataset.

### 2. Sentiment Analysis

VADER Sentiment Analyzer was used to calculate the sentiment compound score for each review.

The following thresholds were used:

- Compound score >= 0.05 → Positive
- Compound score <= -0.05 → Negative
- Between -0.05 and 0.05 → Neutral

### 3. Sentiment Score

A sentiment score was calculated for every review using the VADER sentiment analyzer.

### 4. Visualization

Matplotlib was used to create visualizations showing overall sentiment and sentiment distribution by source.

## Important Note

The original dataset contains Positive and Negative labels. The **Neutral** category in this project is generated by VADER based on the compound sentiment score.

Therefore, Neutral is a predicted category rather than an original dataset label.
